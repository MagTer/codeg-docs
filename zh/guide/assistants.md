# 助手

**助手**是一次你预先配置好的委派：一个智能体、它选定好的每一项选项、它在每个任务上都要遵守的常驻指令，再加上名称、头像和简介。在输入框里用 `@` 提及它，你正在对话的智能体就会把任务交给它——这正是你本来就会提出的那种[委派](/zh/guide/multi-agent)，只是不必每次都重新说明用哪个智能体、哪个模型、哪种模式和哪些规则。主导智能体也可以根据简介自行挑选一个助手。助手功能在 **0.36.0** 中推出。

::: warning 必须先开启委派
助手本身就是一次委派，所以它需要打开**设置 → 协作 → 多智能体协同 → 通用**下的**启用委托**（默认关闭）——而且和任何委派一样，主导智能体必须是在你打开它之后才启动的。委派关闭期间，助手配置标签页会说明这一点，并附带一个**前往「通用」** 按钮。→ [开启它](/zh/guide/multi-agent#turn-it-on)
:::

## 创建一个助手 {#create-one}

打开**设置 → 协作 → 多智能体协同 → 助手配置**，选择**新建助手**。编辑器分为三部分。

- **头像、名称和简介。** 名称最多 40 个字符，在你的助手之间不能重名（不区分大小写）。简介最多 200 个字符，说明**什么时候用**这个助手：它显示在提及面板中名称的下方，也会交给发起委派的智能体，后者自行挑选助手时就以它为依据。头像一开始是名称的第一个字，底色由名称决定。点击头像可以选择**字母**、**Emoji**——有六十个可选，也可以自己输入——或**图片**，即上传一张图片，裁成正方形并缩小到 128×128。字母头像和 Emoji 头像可以选用十种颜色之一。
- **智能体，以及它的每一项选项。** 先选智能体——已停用的不会出现在列表里，未安装的会列出但不能选——然后为它的**每一项**选项选定一个值：先选模型，它会载入与这个模型配套的选项，其余的再按智能体自己的顺序排列。没有任何预选项，也没有*默认*，因为助手就按你所选的内容运行；智能体推荐的值只会被标上**推荐**。在智能体提供了可选值的每一项都选定之前无法保存，底部会统计还剩几项未选。
- **常驻指令**——最多 20,000 个字符，带实时计数：这个助手要遵守的角色和工作要求。它们会随交给该智能体的**每一个**任务一起送达，被恢复的任务也不例外，而且不会显示在它会话的消息里。

**创建**会保存这个助手，并且是开启状态。这个标签页上的改动随改随生效——这里没有需要按的**保存**，这一点和它旁边的两个标签页不同。

## 使用助手 {#use-one}

**提及它。** 在输入框里输入 `@`。自 0.36.0 起，提及面板多了一个**助手**标签页，紧跟在**智能体**之后，列出那些已开启、且所用智能体已启用的助手。选中一个，它就会作为一个带头像的徽标落入你的消息。和[提及智能体](/zh/guide/multi-agent#delegate-with-an-mention)一样，它会被读作一条把这项工作委派给该助手的明确指令，所以请在同一句话里说明任务是什么：

```text
@代码审查员 在我合并之前，检查一下这个分支上的改动。
```

同一个面板在[待办任务](/zh/guide/tasks)和[自动化](/zh/guide/automations)的编辑器里同样可用，适用于其智能体需要把工作转交出去的任务或运行。

**或者让主导智能体来选。** 委派工具会告诉主导智能体，在它的会话启动时有哪些助手是开启的——每个助手的名称、智能体和简介——因此主导智能体在决定由谁来接手某项工作时，可以按简介挑选一个助手。之后才创建的助手，在同一个会话里仍然可以通过提及来调用，因为助手是在主导智能体调用它的那一刻才去查找的；主导智能体自己的那份列表，要等它的智能体下一次启动时才会更新。

## 实际运行的是什么 {#what-runs}

委派给助手时，运行的是**它的那套配置**：它的智能体、它保存的选项和它的常驻指令。主导智能体只决定任务，以及（如果它愿意）在哪个文件夹里工作。主导智能体点名的任何智能体都会被忽略，你的[子智能体配置](/zh/reference/settings/collaboration#multi-agent-collaboration)也不适用——那是委派给普通智能体时才用的。如果智能体在你保存助手之后新增了某个选项，这个选项会沿用智能体自己的值；保存的值已不再被智能体提供的选项也是如此——比如在一次更新之后——因为子智能体启动时会跳过这个值，而不是让任务失败。编辑器把某个选项标为*不可用*时，请重新选择。

子智能体会保留一份任务开始时该助手的快照，因此一个被中断后又[恢复](/zh/guide/multi-agent#a-sub-task-that-was-cut-off-can-be-picked-up)的任务，即使你在此期间编辑或删除了这个助手，仍会按原来的配置运行。

此后它就是一次普通的委派：主导智能体回复里的一张卡片、一段属于它自己的对话、它自己的权限提示。卡片上显示助手的头像，头像上带着它所运行的智能体的小标记，名称后面跟着智能体的名称。子智能体的[会话详情](/zh/guide/side-panel#session-details)里有一行**助手**，它在侧边栏里的那一行显示的是助手的头像，而不是智能体的图标。

## 委派没能成功时 {#when-it-doesn-t-go-through}

委派卡片上的徽标会说明原因：

| 徽标 | 发生了什么 |
| ----- | ------------- |
| **助手不存在** | 它已被删除或关闭，或者主导智能体给出了一个不存在的 id。主导智能体会被告知它可以用哪些助手——并且不要改把任务交给别的智能体 |
| **启动失败** | 该助手的智能体已停用或未安装 |
| **需要重启** | Codeg 还没有完成升级。重启 **Codeg**——不是智能体——然后再试一次 |
| **未响应** | Codeg 没能及时响应，主导智能体会被告知稍后再试 |

## 管理助手 {#manage-them}

**助手配置**标签页按顺序列出你的助手，每一个都带着头像、简介，以及它的智能体和后面最多三项已保存的选择。智能体**未安装**或**已停用**的助手会带一个标记。

- **调整顺序**：拖动一行的把手，或者让把手获得焦点后按 **↑** 或 **↓**。
- **关闭一个助手**：用它自己的开关。它会立即从提及面板中消失，也不能再被委派；已经在运行的主导智能体在它的智能体下次启动之前仍会列出它，但调用它会被拒绝。它会一直留在这里，直到你重新打开它。
- **编辑**：点铅笔按钮，或者直接点击这一行。如果智能体的选项在你保存之后有了变化——某个值它已不再提供，或者它新增了某个选项——编辑器会把它们标出来，标为 *不可用（原为 …）* 或**新增**，并请你重新选择。智能体已停用或未安装的助手，会以只读方式显示它保存的选项。
- **创建副本**（在 **⋯** 菜单里）会生成一个名为 *名称 (2)* 的副本。
- **删除**之前会先确认。这个助手会从设置和提及面板中消失，也不能再被委派，但你对话里已有的委派卡片仍会显示它，并标上 *（已删除）*。

[配置同步](/zh/reference/settings/system#configuration-sync)会把你的助手带到你的其他设备上；如果同步过来的助手与本机另一个已有的助手重名，它会被改名为 *名称 (2)*。

## 值得了解 {#good-to-know}

- **助手是一套预设，不是一位同事。** 它在任务之间不保留任何记忆：每次委派都是冷启动，只凭主导智能体写下的任务和常驻指令。把常驻指令写成适用于任何任务的规则，把只属于某一个任务的内容留在消息里。
- **常驻指令会送到智能体的模型提供商那里。** 它们是子智能体发给其模型的提示词的一部分，智能体自己存在磁盘上的历史记录也会保留它们，尽管 Codeg 不会在会话里显示它们。
- **谁能使用助手。** 任何能够[主导委派](/zh/guide/multi-agent#how-delegation-works)的智能体——十九个内置智能体中的十六个——都能把工作交给助手。助手自己的智能体则可以是任何一个你能委派给它的智能体。
