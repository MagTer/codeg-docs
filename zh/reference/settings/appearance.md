# 外观

**设置 → 外观** 控制 Codeg 的呈现方式：浅色还是深色、强调色、叠加在它之上的你自己的配色、整体绘制的大小、各个区域使用的字体、一张可选的背景图片、对话怎样动起来又铺开多宽，以及一些额外功能。它是设置窗口默认打开的界面，这里的每一项改动都会自动保存并立即生效 —— 没有保存按钮，也无需重启。（只有一个例外：自定义 CSS 编辑器是实时预览、按**应用**保存的。）

## 主题模式 {#theme-mode}

一个下拉选择器 —— **跟随系统**、**浅色** 或 **深色**。*跟随系统* 会追随你的操作系统设置并随之切换；下方的文字会显示它当前解析出的*实际*主题。在桌面应用中，原生窗口也会随之切换。

## 主题颜色 {#theme-color}

用于按钮、强调元素和高亮的强调色调色板。共十二种预设 —— 标准的 shadcn 主题色，每种都是一个可点击的色块：

**Neutral** *（默认）* · Zinc · Slate · Stone · Gray · Red · Rose · Orange · Green · Blue · Yellow · Violet

选择后会立即为整个应用重新着色。前五种 —— **Neutral** *（默认）*、Zinc、Slate、Stone 和 Gray —— 会让所有表面保持灰色；而七种**强调色**（Red、Rose、Orange、Green、Blue、Yellow、Violet）走得更远，会用该色调为面板、侧栏、画布，乃至代码编辑器背景着色。这是自动的 —— 没有单独的开关。

## 自定义样式 {#custom-style}

十二套预设是起点，不是天花板。**自定义样式**——默认收起，标题旁用一行摘要说明它当前在做什么（*使用预设默认值*、*3 项覆盖*、*自定义 CSS*，或*已停用*）——让你改动应用里的任意颜色、把每一个圆角调圆，以及在你坚持的情况下，直接写原始 CSS。

这些覆盖是**叠加在基底预设之上**的，而不是替换它，所以之后切换预设也不会丢失它们。

### 颜色与圆角 {#colors-and-corners}

**启用自定义配色**会打开调色面板：**31 个语义色变量**，与 shadcn 文档中的那一套完全相同。其中七个摆在正面——*primary*、*primary foreground*、*background*、*foreground*、*accent*、*border*、*sidebar*——之所以选它们，是因为改了立刻看得见、又不容易把界面弄坏；其余 **24 个收在「高级」里**（卡片、浮层、muted 与 secondary 表面、destructive、input、ring、五个图表色，以及侧边栏自己那一套）。

关于怎么改它们，有两点要知道：

- **浅色和深色是分开设置的。** 你此刻编辑的是应用当前所处那个模式的取值，面板上会直接说明——*"正在编辑浅色模式的取值。切换到深色模式可单独设置它。"*
- **每一项都能还回去。** 改过的变量旁边有一个**重置**控件，可以把它恢复成预设的取值；**清除覆盖**则一次全部还原。

**圆角**是一个滑块，而且它驱动的是从 `sm` 到 `4xl` 的整条尺度——所以拖一下就能让整个应用从锐角变成完全圆润，别的什么都不用动。

### 把主题带走 {#take-a-theme-with-you}

你的配色是按 shadcn 的 `registry:theme` 形状存储的，这让它在两个方向上都可以流通：

- **复制主题 JSON** 把当前的浅色/深色这一对放到剪贴板上。
- **导入主题…** 接受一个 `registry:theme` 条目、一个裸的 `light`/`dark` 对象，或者一张扁平的变量表——因此来自 tweakcn、shadcn 官方 registry 或同事分享的主题都能直接粘进来。**读取剪贴板**会替你把内容填进输入框。

导出的主题可以用 `shadcn add` 装进任何 shadcn 项目，而任何 shadcn 主题在这里都能用。这个格式没有任何 Codeg 专有的部分。

### 自定义 CSS *（高级）* {#custom-css-advanced}

对于字段覆盖不到的地方，**启用自定义 CSS** 会打开一个编辑器，它作用于**每一个 Codeg 窗口**。对话框实时预览，按**应用**保存；它会显示你用掉了 **64 KB** 预算的多少，以及解析出了多少条规则——这样一段没能解析成功的样式表会明确说出来，而不是默默什么都不做。

有两样东西会被点出来，但只有一样会被移除：

- **`@import` 规则会被剥掉**——它们会去拉取远程样式表。如果有一条通过转义写法逃过了移除，那么整段都会被拒绝保存，而不是被放行。
- **远程 `url()` 会被点名，但会被保留。** 这是你的样式表，Codeg 不去改写它——它只是确保你知道：应用它就会发起一次网络请求。→ [隐私与安全](/zh/reference/privacy)

你的颜色覆盖在里面可以当作普通变量使用——`var(--primary)`、`var(--background)` 等等。

::: warning 万一你把界面写坏了，有两条出路
自定义 CSS 会覆盖每一条内置样式，这意味着它真的能把应用弄到不可用——一个位置不对的 `display: none`，就没有任何东西可以点了。所以这里有两条不依赖界面本身还能工作的逃生舱：

- **⌘⌥⇧S**（Ctrl+Alt+Shift+S）停用全部自定义样式——配色和 CSS 都停——同一组键再按一次恢复。它刻意是一个三修饰键组合，并且被安排在所有事件之前监听。→ [快捷键](/zh/reference/settings/shortcuts)
- 在窗口 URL 上加 **`?safeStyle=1`**，只让**那一个窗口**忽略自定义样式，其他窗口不受影响。

两者任一生效期间，这个区块会明确说明，并提供**恢复自定义样式**。
:::

## 窗口缩放 {#window-zoom}

按离散档位缩放整个界面 —— 文字、控件和间距一并缩放：

**80% · 90% · 100%** *（默认）* **· 110% · 125% · 150% · 175% · 200% · 250% · 300%**

最上面四档是 **0.28.2** 新增的，把上限从 150% 提到了 **300%** —— 足以隔着一段距离操作 Codeg，或者在视力不佳时不必动用系统级放大镜就能看清。

改它不必特地来这里：**⌘=** 与 **⌘−** 按同样的档位调整，**⌘0** 回到 100%。唯一会被拒绝的地方是 **Windows 与 Linux 上的终端内部**——那里 `Ctrl+−` 和 `Ctrl+=` 带有 shell 语义，属于你正在跑的那个程序；macOS 用的是 Cmd，不会冲突，所以终端里照样能缩放。→ [快捷键](/zh/reference/settings/shortcuts)

缩放比例**按设备**存储，因此大尺寸外接显示器和笔记本屏幕可以各自保留适合自己的大小。

## 字体 {#fonts}

三种相互独立的字体，每个区域一种。每一种都可以从一组内置字体族（分为 **Sans-serif** / **Monospace** 两组）中选择，或选择 **Custom…**，以指定你系统上安装的任意字体。内置字体仅在被选中时才加载。可设置的内容因区域而异：

| 区域 | 字体列表 | 字号 | 连字 | 自动换行 |
| ------- | --------- | ---- | --------- | --------- |
| **界面** | Sans + monospace | — | — | — |
| **编辑器** | Monospace | ✓ | ✓ | ✓ |
| **终端** | Monospace | ✓ | ✓ | — |

- **连字** 会为支持连字的字体开启编程连字（`=>`、`!=`、`>=`）；对于不支持的字体，该开关会自行禁用并加以说明。终端连字仅对内置的编程字体生效。
- 底部有一个**实时预览**，会用你当前的选择渲染一行界面文本、一段代码片段和一条终端命令 —— 让你在确定前先做比较。

这些设置所影响的编辑器和终端，就是[工作区](/zh/guide/workspace)中的那些。

## 工作区背景 {#workspace-background}

在整个工作区背后放一张图片。打开**启用背景图片**并选择一张图片（**PNG、JPEG、WebP 或 GIF**，最大 **16 MB**）；侧栏、面板和标签栏会变半透明并**磨砂**，让图片透出来，同时一层遮罩保证文字可读。浅色和深色模式共用同一张图片。

**GIF 是 0.28 加入这份清单的**，而且动图会**动起来**——透过模糊和磨砂面板一起动，而不只是显示静止的第一帧。

**或者你也可以不自带图片。** 从 **0.30.4** 起，一个**壁纸市场**按钮会在设置里打开 [Wallhaven](https://wallhaven.cc) 的公开图库 —— **仅 SFW**，可按**全部**、**综合**、**动漫**或**人物**筛选，并带搜索框与分页。点一张壁纸，Codeg 一步完成下载并应用；你正在用的那张会标上**使用中**。一张做不了背景的图片 —— 超过 **16 MB**，或超过 **4000 万像素** —— 会置灰为**不可用**并写明原因，这些数字直接读自图库列表，所以你在花掉那次下载之前就会知道。Wallhaven 并不总是把这两个数字都提供出来，缺了它们的卡片仍然可以点；那里的限制会在下载真正跑起来时才生效。

自上而下的各项控制：

| 控制项 | 作用 | 默认 |
| ------- | ------------ | ------- |
| **启用背景图片** | 整个功能的开关 | 关闭 |
| **图片** | 选择、更换或移除图片 | —— |
| **填充方式** | 图片如何摆放：**覆盖**、**适应**、**居中**或**平铺** | 覆盖 |
| **遮罩不透明度** | 让图片朝主题背景淡化 —— 数值越高，文字对比度越强（最高 99%） | 82% |
| **图片模糊** | 柔化图片，0–24 px | 0 px |
| **面板不透明度** | 侧栏、面板和标签栏有多不透明 —— 越低，透出的图片越多，直至完全透明 | 30% |

::: tip 它也会带到浏览器
图片与 Codeg 的数据一起保存在磁盘上，因此你在桌面端设置的背景，在你把同一份安装作为[服务器](/zh/getting-started/deployment)于浏览器中打开时也会显示。显示相关的设置（不透明度、模糊、填充）像缩放一样按设备存储。
:::

## 模式选择区域 {#mode-selection-area}

一个开关 —— **在新对话页面显示**。它控制当你打开一个全新对话时，**代码开发 / 办公工作** 的快捷卡片是否出现在 composer 上方。保持开启即可一键使用欢迎界面的快捷操作 —— 它们会为 [Office](/zh/guide/office) 和 [Research](/zh/guide/research) 等技能填入一段起始提示词 —— 或者关闭它，得到一个简洁的 composer。

## 聊天区域动画 {#chat-animations}

一个开关 —— **启用聊天区域动画**，默认**开启**，**0.35.0** 新增。关掉它，对话就不再有动效：展开与收起、工具调用与工作状态的动画、一条回复的折叠收起，以及平滑滚动，都会一步到位 —— 从**消息导航**的跳转、跳回某条回复所对应的提示词也包括在内，[回复卡片](/zh/guide/skills#cards-tables-and-charts-in-replies)里的图表同样如此。加载转圈图标照转不误，因为一个停住的转圈看起来就像卡死了。

它只作用于**对话区域**；侧栏、抽屉和应用的其余部分照旧有动画。它在首次绘制之前就已生效，所以关着它重新加载时，连一次动画都不会出现。

## 聊天区域宽度 {#chat-width}

对话列和 composer 最多能铺开多宽 —— *"会话列与输入框的最大宽度。"* **0.35.0** 新增。

- **内容宽度**是一个滑块，从 **640 px** 起，以 8 为步长，在你挪动它之前显示为**默认（768px）**。**恢复默认**会把它还原。
- **也可以直接拖动聊天列本身。** 在对话标签页里，聊天列的左右边缘各有一个把手：把任意一个往外拖，列就会向两侧同时变宽；**双击**它恢复默认；也可以让它获得焦点后用 **←** / **→** 调整，每按一次 32 px，按 **Esc** 或 **Home** 恢复默认。只有在至少 768 px 宽的窗口里，这些把手才会出现。
- **按 100% 缩放计。** 宽度按 100% [窗口缩放](#window-zoom)下的数值存储，并随缩放等比变化，默认值一直都是这样。比窗口能显示的更宽的值，会被限制在放得下的宽度，两侧各留一点边距，而存储的值保持不变。

这个宽度会作用于每一个绘制对话记录的界面 —— 对话标签页及其欢迎页、[画布](/zh/guide/canvas)上的卡片、待办任务或子智能体的只读视图 —— 但只有对话标签页带有把手。在一个窗口里改动它，其他窗口会跟着变。

## 桌面宠物 {#desktop-pet}

一个可折叠的**桌面浮动伙伴**管理器 —— 停留在你屏幕上的动画精灵角色，同时兼作实时状态指示器，显示有多少个智能体会话正在运行、等待审批或出错。它默认处于折叠状态；标题旁的数字表示你拥有的宠物数量。

添加宠物有三种方式：

- **添加宠物** —— 提供你自己的精灵表：一张**带透明通道的 1536×1872 PNG 或 WebP**（与 Codex 兼容），外加一个 id 和一个显示名称。
- **从 Codex 导入** —— 拉取任何已安装在 `~/.codex/pets/` 下的宠物；没有时该选项被禁用。
- **宠物市场** —— 浏览并安装社区宠物，可按类别（物件、动物、人物、生物）筛选，并按最新、热门或浏览量最高排序。

每个宠物卡片都可以让你**设为激活**、**编辑**或**删除**（激活中的宠物无法删除），点击卡片可预览动画 —— 待机、奔跑、挥手、跳跃，以及各种会话状态姿势。**召唤宠物窗口** 会让激活的宠物浮动在你的桌面上。

::: info 浮动宠物仅限桌面端
召唤屏幕上的伙伴需要原生桌面窗口，因此 **召唤** 仅在桌面应用中出现。你仍然可以在[浏览器会话](/zh/getting-started/deployment)中构建和管理你的宠物库 —— 只是没有地方让它浮动而已。
:::

## 值得了解 {#good-to-know}

- **外观是本地的。** 这些是按机器保存的偏好设置 —— 缩放尤其如此 —— 并不属于任何同步的配置文件。在每台设备上各设置一次。
- **应用语言不在这里。** 界面语言位于[系统](/zh/reference/settings/system)界面，而非外观。
- **几乎一切都是即时的。** 本界面上没有任何控件需要重新连接或重启；唯一需要按按钮的是自定义 CSS 编辑器，它实时预览、按**应用**保存。
- **自定义样式跟着设备走，不跟着账号走。** 你的颜色覆盖和 CSS 存在你设置它们的那个浏览器或应用里——和缩放一样；而背景图片不同，它的文件是与 Codeg 的数据一起存放的。
