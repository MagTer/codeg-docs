# 快捷键

**设置 → 快捷键** 列出了 Codeg 所响应的每一个键盘快捷键，并让你重新绑定其中任意一个。每一行是一个操作 —— 它的名称、一段简短描述，以及一个显示其当前绑定的按钮。通过*录制*新的组合键来更改某一项；用一个按钮重置整套快捷键。

::: tip 记号说明
在下文中，**⌘** 代表主修饰键：在 macOS 上是 **Command**，在 Windows 和 Linux 上是 **Ctrl**（Codeg 会显示你的操作系统所用的那一个）。**⇧** 是 Shift，**⌥** 是 Option / Alt。
:::

## 重新绑定快捷键 {#rebinding-a-shortcut}

点击某一行的快捷键按钮 —— 它会切换为 **按下快捷键…** —— 然后按下你想要的组合。录制器会执行几条规则：

- **必须包含一个修饰键。** 大多数操作需要 **Ctrl/Cmd 或 Alt**（可选配合 Shift）；单独一个字母不会被识别。两个 composer 操作 —— *发送消息* 和 *消息内换行* —— 是例外，它们接受像 <kbd>Enter</kbd> 这样的单个按键。
- **冲突会被拒绝。** 如果该组合已经属于另一个操作，Codeg 会拒绝它并告诉你哪个操作占用了它 —— 这样你就无法悄无声息地覆盖一个已有的绑定。
- **Esc 取消** 录制，不做任何更改。

**重置为默认值**（右上角）会一次性恢复所有快捷键；当没有任何改动时它处于禁用状态。

## 默认快捷键 {#the-default-shortcuts}

### 面板与布局 {#panels-layout}

| 操作 | 快捷键 | 作用 |
| ------ | -------- | ------------ |
| **打开搜索** | ⌘K | 显示或隐藏对话搜索面板 |
| **切换左侧边栏** | ⌘B | 显示或隐藏对话列表侧边栏 |
| **切换终端** | ⌘J | 显示或隐藏底部终端面板 |
| **切换右侧面板** | ⌘E | 显示或隐藏辅助信息面板 |

### 标签页、窗口与导航 {#tabs-windows-navigation}

| 操作 | 快捷键 | 作用 |
| ------ | -------- | ------------ |
| **新建对话** | ⌘T | 在当前文件夹中创建一个新的对话标签页 |
| **新建终端** | ⌘T | 创建一个新的终端标签页（当焦点在终端上时） |
| **打开文件夹** | ⌘O | 在新窗口中打开文件夹选择器 |
| **打开设置** | ⌘, | 打开设置窗口 |
| **关闭当前标签页** | ⌘W | 关闭当前的对话或文件标签页 |
| **关闭当前终端** | ⌘W | 关闭当前的终端标签页（当焦点在终端上时） |
| **关闭所有文件标签页** | ⌘⇧W | 关闭所有打开的文件标签页（当文件面板处于活动状态时） |
| **下一个标签页** | ⌘Tab | 切换到下一个对话或文件标签页 |
| **上一个标签页** | ⌘⇧Tab | 切换到上一个对话或文件标签页 |
| **跳到第 1–9 个标签页** | ⌘1 … ⌘9 | 按位置直接跳到那个标签页 |
| **重开已关闭的标签页** | ⌘⇧T | 把你刚关掉的那个标签页找回来 |

### Composer {#composer}

| 操作 | 快捷键 | 作用 |
| ------ | -------- | ------------ |
| **发送消息** | Enter | 发送输入框中的当前消息 |
| **消息内换行** | ⇧Enter | 在消息输入框中插入一个换行 |

### 外观 {#appearance}

| 操作 | 快捷键 | 作用 |
| ------ | -------- | ------------ |
| **停用/恢复自定义样式** | ⌘⌥⇧S | 关闭全部[自定义配色与 CSS](/zh/reference/settings/appearance#custom-style)，再按一次恢复 |
| **放大** | ⌘= | 把[窗口缩放](/zh/reference/settings/appearance#window-zoom)向上调一档 |
| **缩小** | ⌘− | 向下调一档 |
| **重置缩放** | ⌘0 | 回到 100% |

这三个缩放按键走的是外观页提供的同一组离散档位，到两端就停住，不会绕回去。**⌘=** 是美式键盘在按 *Ctrl/Cmd +* 时实际发出的未加 Shift 的按键，所以 **⌘⇧+** 和小键盘的 `+` 同样有效。在**终端**内部，Windows 与 Linux 上的 Ctrl 形式会被拒绝——`Ctrl+−` 与 `Ctrl+=` 属于里面正在跑的程序——而 macOS 照样缩放，因为 Cmd 没有 shell 语义。

## 值得了解 {#good-to-know}

- **新增的默认绑定会为你已有的绑定让开。** 这三个是 **0.28.2** 新加的；如果你保存的配置里已经把 ⌘0 绑给了自己的某个操作，那个绑定会保住这个组合键，而*重置缩放*会以**未分配**的状态出现——需要你在这个页面手动绑一个。在这项修复之前，晚于你配置文件出现的新默认绑定会直接盖在你的绑定上，一次按键同时触发两个操作，而屏幕上没有任何提示。这项检查比对的是写下来的组合键，所以它唯一看不见的情形是**键盘布局层面的撞车**：在 AZERTY 上，`Ctrl+−` 同时也是 `6` 键所在的位置，于是你绑在 `⌘6` 上的操作仍可能与*缩小*一起触发。如果一次按键触发了两件事，把其中一个改绑即可。
- **重开不会把你删掉的东西找回来。** ⌘⇧T 找回的是你*关闭*的标签页；被你**删除**的对话会从重开栈里被撤下，所以这个快捷键没法从后门撤销一次删除。
- **有些绑定是刻意共享的。** ⌘T 和 ⌘W 各自驱动两个操作 —— 一个*终端*操作和一个*对话/文件标签页*操作 —— Codeg 会根据当前焦点选择正确的那一个。这就是为什么默认设置里有一些表面上重复、而冲突检查仍然允许的绑定：当终端处于焦点时，**⌘T** 打开一个新终端，否则打开一个新对话；**⌘W** 关闭处于焦点的终端或当前标签页。
- **只有 composer 的按键可以不带修饰键。** *发送消息* 和 *消息内换行* 是仅有的两个你可以绑定到单个按键的操作 —— 如果你愿意，可以对调它们（比如用 <kbd>⇧Enter</kbd> 发送、<kbd>Enter</kbd> 换行）。
- **自定义样式那个快捷键是逃生舱，也是照逃生舱来做的。** 自定义 CSS 可能让你面对一个点不动的界面，所以这个绑定刻意选了一个不与任何东西冲突的三修饰键组合，而且 Codeg 会先于其他一切监听它——即便界面已经被样式改到无法使用，它依然按得动。你当然可以改绑它，但请留一个闭着眼也能按到的组合。
- **有两个按键没有列在这里，因为它们是固定的。** 在空着的消息输入框里按 **Tab**，会填入 Claude Code [建议](/zh/guide/conversations#let-claude-code-suggest-the-next-prompt)的提示词——它先于任何绑定生效，所以即便你把*发送消息*绑到了 Tab 上，也是它说了算——而 **Alt+↑ / Alt+↓** 会把获得焦点的标签页在[右侧面板](/zh/guide/side-panel#the-tab-rail)的标签栏上上移或下移。这两个都不能改绑。
- **快捷键保存在设备上。** 它们存放在应用的本地存储中，按设备保存 —— 不属于同步的配置文件。和[外观](/zh/reference/settings/appearance)一样，在每台机器上各设置一次。
