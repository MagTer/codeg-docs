# Web 服务

**设置 → Web 服务** 把你正在运行的 Codeg 变成一台**可以从浏览器访问的服务器** —— 你的手机、平板，或同一网络上的另一台笔记本。界面对它的总结是：*“启用后可通过浏览器远程访问 Codeg。”* 启动服务，把浏览器指向它打印出的地址，输入一次令牌，你就在另一台设备上拥有了完整的工作区 —— 相同的对话、智能体和设置。

::: info 本质上仅限桌面端
这是唯一一个**只在桌面应用中出现**的设置界面。它是那个*开启*浏览器访问的开关，所以在浏览器会话内部它无事可做 —— 你无法从它所通向的房间里去关闭那扇门。本界面上的一切都会自动保存；没有保存按钮。
:::

## 端口 {#port}

服务监听的 TCP 端口 —— 默认 **3080**。可选择任意空闲端口；该字段是一个普通的数字输入框。**低于 1024** 的端口通常需要提升权限，因此如果某个低端口以*权限被拒绝*启动失败，请选择一个更高的。

服务**运行时端口被锁定** —— 要更改它，请先停止服务。

## 访问令牌 {#access-token}

这扇门的密码。任何打开该地址的人，在从某台设备**首次**连接时都会被要求输入这个令牌；没有它就进不来。该字段提供三个控件：

- **重新生成**（↻）—— 铸造一个全新的随机令牌。如果你觉得旧的泄露了，这很方便。
- **显示 / 隐藏**（眼睛）—— 显示令牌以便读取或输入。
- **复制** —— 抓取它以粘贴到另一台设备。

把该字段**留空，Codeg 会在你启动服务时自动生成一个令牌**。和端口一样，令牌在运行时被锁定 —— 停止后才能更改。因为这个令牌是横亘在你的工作区和网络上其他所有人之间的唯一屏障，请把它当作密码对待；它如何被存储和传输，在[隐私与安全](/zh/reference/privacy)中有所介绍。

## 自动启动 {#auto-start}

一个开关 —— **Codeg 启动时启动 Web 服务**。打开它，你就不必在每次重启后都造访这个界面；服务器会用你保存的端口和令牌自动启动。与其他字段不同，你可以在服务运行时切换这一项。

## 启动与停止 {#starting-and-stopping}

**状态** 行显示一个绿点和 *运行中*，或一个灰点和 *已停止*，并配有一个在 **启动** 和 **停止** 之间切换的按钮（操作进行中时它显示 *处理中…*）。你编辑过的配置 —— 端口、令牌 —— 会在下一次 **启动** 时应用，这就是为什么这些字段在服务运行后会锁定。

如果启动失败，原因会就地显示 —— 最常见的是端口已被占用（*端口 N 已被占用*）、端口需要更高的权限，或该地址在这台机器上不可用。更改端口或释放它，然后重试。

## 访问地址 {#the-access-address}

服务一旦**运行**，就会出现一个 **访问地址** 部分，显示要打开的 URL。服务绑定到**所有网络接口**（`0.0.0.0`），因此它会同时在这台机器的*每一个*本地地址上可达 —— 同一台电脑用回环地址，其他设备用局域网 IP。当地址不止一个时，一个下拉框让你选择显示哪一个；该选择**仅影响显示**且会被记住 —— 它改变的是各按钮作用于哪个地址，绝不会改变服务实际监听的地方。旁边有三个圆形按钮：

- **复制** —— 复制该地址。
- **二维码** —— 弹出一个二维码，你可以*“用手机扫描以在浏览器中打开 Codeg”* —— 这是登上移动设备最快的方式。
- **打开**（↗）—— 在你的默认浏览器中打开该地址。

## 当端口被占用时 {#when-the-port-is-busy}

如果服务已停止，但 Codeg 注意到所配置的端口已被**另一个进程占用**（或处于不明状态），它会在你按下启动之前就显示一条琥珀色横幅 —— *“在端口被释放之前，Codeg 无法在此绑定。请更改上方的端口，或关闭占用它的进程。”* 这是一个提醒：直接启动会以*端口被占用*失败，通常源于某个遗留的监听器或一次孤立的先前运行。

## 值得了解 {#good-to-know}

- **这是你的桌面应用，只是共享出去。** 浏览器客户端不是一个精简版 —— 它就是同一个 Codeg，只不过被远程驱动。这与[无头服务器部署](/zh/getting-started/deployment)不同，在那种部署中，一个专用的 `codeg-server` 二进制文件（或 Docker）*就是*整个安装，根本没有桌面。相同的浏览器体验，两种不同的来源 —— 当你已经在运行桌面应用、只是想从另一台设备访问它时，就选这个界面。
- **可达就意味着可达。** 绑定到 `0.0.0.0` 意味着任何能在那个端口路由到你机器的人都能触及登录界面 —— 这正是令牌重要的原因。在不受信任的网络上，请保持令牌强度，并在用完后停止服务。
- **一切自动保存。** 端口、令牌和自动启动会随你的更改而持久保存；没有保存按钮。对端口和令牌的编辑会在你下次启动时生效。
- **服务绑定在这台机器上。** 其他设备通过网络访问它，但工作区、文件和智能体仍然全部运行在这里 —— 浏览器只是通往它们的一扇窗。
- **webhook 也落在这里。** 服务运行期间，它就是 forge 投递[仓库面板 webhook](/zh/guide/repository#set-up-the-webhook) 的地址 —— 这条路由不要求访问令牌，而是改为校验每次推送的签名。停止服务，桌面应用就不再接收它们；定时扫描则不需要它。→ [隐私与安全](/zh/reference/privacy#webhooks-for-auto-processing)
- **浏览器可以保存一份应用副本。** 通过 HTTPS 或在 `localhost` 上访问时，网页版会缓存它自己的文件，这样重新打开时就不必再下载一遍 Codeg。→ [部署](/zh/getting-started/deployment#install-it-as-an-app)
